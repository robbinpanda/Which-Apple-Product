# Which Apple Product

一个面向二手选购的 Apple 产品对比网站。用户可以按机型、年份和系列筛选，选择官方存在的芯片与配置组合，并同时比较 CPU 单核、CPU 多核、GPU、关键规格和二手购入估值。

项目是零依赖静态站点，直接由 HTML、CSS 和原生 JavaScript 构成。

## 当前数据范围

- 数据快照：2026-08-17
- 发布年份：2016–2026
- iPhone：40 款
- iPad：34 款
- MacBook：43 款
- 产品合计：117 款
- 被产品引用的芯片 / GPU 配置：134 个
- 可选择的官方合法目标配置：1,242 组

机型、芯片档、内存与存储绑定、屏幕、分辨率、刷新率、重量、电池和接口以 Apple 中国技术规格页为主口径。每款产品均保留 Apple 官方页面直达链接。

## 主要功能

- iPhone、iPad、MacBook 三个大分类。
- 按年份、系列、关键词筛选。
- 按发布时间、单核、多核、GPU 或闲鱼估值排序。
- CPU 单核、CPU 多核和 GPU 三项分开显示。
- 每一性能列独立归一化条形长度，当前结果中的该列第一名始终满格。
- 同一机型可切换多个官方芯片档，性能、价格、重量、续航、电源、接口、内存带宽、媒体引擎、外接显示器和 Apple 规格链接同步变化。
- 内存与存储采用单一“目标规格组合”选择器，避免生成不存在的配置。
- 支持 iPad Pro 容量—内存—CPU 绑定和 MacBook Pro / Max 的专属容量限制。
- 一键复位当前分类全部已调整配置，不改变筛选、排序和已保存的对比快照。
- 最多保存四个当前配置快照进行并排比较。
- 桌面使用紧凑表格，窄屏自动切换卡片。

## 性能评分

百分比是固定基准下的相对性能指数，不是发布会倍数，也不是主观打分。

- iPhone：A14 Bionic = 100%
- iPad：M1（iPad）= 100%
- MacBook：M1（8 核 CPU / 8 核 GPU）= 100%

Mac CPU 综合 Geekbench 6、Cinebench 2024 与 PassMark；GPU 综合 Geekbench Compute、可比的 3DMark 项和 FP32。各原始项先相对固定基准归一化，再使用加权几何平均。

NanoReview 只作为公开跑分聚合入口之一，不使用其不透明的 Final Score。缺少某个降配芯片的独立聚合页时，优先查具体设备，再依据同架构相邻档实测和官方核心数推导缺失输入；最终三项性能分仍由统一公式计算。

完整权重、缺项处理和 M1 Pro 案例见[性能与二手价格技术报告](technical-report.html)。

## 二手价格口径

价格是 2026-08 的静态选购估值，不是实时 API、成交保证或保值承诺。

- `闲鱼个人`：正常个人自用机的挂牌 / 近期成交估值。
- `转转验机`：带验机与售后服务的买家零售估值，页面用 `≈` 标明模型属性。
- 平台回收价、故障机、监管机、扩容机和配件打包价不进入正常区间。

统一机况假设为：无激活锁或监管锁、无重大拆修和功能故障、屏幕完整，电池通常不低于约 85%。

旧版价格审计发现（当时尚未清除 Intel 非法组合，共枚举 1,273 组）：

- 转转数值几乎全部等于闲鱼乘约 85%，并非独立采样。
- 28 个高芯片档重复计算了绑定内存 / 存储差价。
- 当时枚举的 1,273 个配置中有 8 个出现 0 元端点。
- 老款 4TB / 8TB 配置可能错误保留近似新机选配差价。

当前模型以公开交易样本建立 28 个代表性 SKU 锚点；没有直接锚点的默认配置，按同类别、同系列和相近年份的锚点加权校准。芯片整包差价与组内内存 / 存储差价分别按机龄折旧，避免 Max 或 iPad Pro 绑定配置重复计价。

转转缺少公开可复核的同 SKU 样本时，根据带平台服务的零售属性生成明确的估值，而不再伪装成独立实测。购买当天可点击价格，用当前机型、芯片、内存和存储直接搜索平台复核。

完整样本、折旧率、公式和修正前后案例见[技术报告的价格审计章节](technical-report.html#market)。

## 本地运行

可以直接打开 `index.html`，也可以在目录中启动任意静态文件服务器。例如：

```bash
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 验证

项目提供零依赖 Node.js 检查：

```bash
node verify.js
```

当前检查覆盖：

- 产品数量与 2016–2026 年份边界。
- 所有芯片配置均存在必要性能输入。
- 官方合法 CPU / GPU / 显存 / 内存 / 存储组合、顺序和绑定关系。
- M1 Pro / Max、M2–M5 Pro / Max 的代表性配置约束，以及每档重量、续航、电源、接口、带宽、媒体引擎和外显字段。
- 2016–2019 Intel 独显 MacBook Pro 的 41 个官方 bundle，不再做 CPU × GPU 全排列；2019 16 英寸包含 5500M 4GB / 8GB 两档。
- 1,242 个价格结果均为有限正数且上下限有序。
- 不再存在“转转 = 闲鱼 × 0.85”的旧机械关系。
- iPhone 电池和未标注刷新率不会伪装成 Apple 官方数据。

浏览器验收还覆盖配置切换、排序重排、一键复位、对比快照、响应式布局和控制台错误。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 主页面、筛选区与弹窗结构 |

| `verify.js` | 零依赖数据及价格完整性检查 |
| `修改报告.md` | 本轮大修改的详细说明与验收记录 |

## 限制

- 跑分会受到系统版本、功耗、散热和样本结构影响。
- 性能指数适合比较硬件层级，不代表每个 App 都会按相同比例加速。
- 闲鱼和转转完整搜索结果依赖登录和动态加载，本站没有声称全站实时抓取。
- 稀有 CTO、AC+、地区版本、成色和电池状态可能使实际价格明显偏离估值。
- 数据更新时应保留样本日期、具体配置与来源，不能只修改一个没有证据的百分比或价格。
