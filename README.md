# Which Apple Product

一个面向二手选购的 Apple 产品对比网站。用户先选择品类、当前配置的闲鱼起价预算和最看重的客观指标，再从缩小后的候选清单中选择官方存在的芯片与配置组合。

项目是零依赖静态站点，直接由 HTML、CSS 和原生 JavaScript 构成。

## 快速入口

- 本地查看：运行 `python -m http.server 4173`，然后访问 `http://127.0.0.1:4173/`。
- 完整验证：运行 `npm test`。
- 方法与数据口径：阅读[性能与二手价格技术报告](docs/technical-report.html)。

- iPad：34 款
- MacBook：43 款

机型、芯片档、内存与存储绑定、屏幕、分辨率、刷新率、重量、电池和接口以 Apple 中国技术规格页为主口径。每款产品均保留 Apple 官方页面直达链接。这里的“核心硬件 SKU”包含会改变机器本体规格或价格的芯片、内存、存储、网络版本与显示玻璃；颜色、单独购买的电源适配器、AppleCare / 保障和其他配件不计入。

## 主要功能

- iPhone、iPad、MacBook 三个大分类。
- 按当前配置闲鱼起价预算筛选；预算含义在控件与结果摘要中直接注明。
- “优先看”可直接切换新款、低价、单核、多核或 GPU，不创建不透明的综合推荐分。
- 搜索支持空格分词和常见连字符写法，并覆盖机型、芯片、内存、存储、刷新率、接口、Pencil 等动态规格；命中非默认芯片或容量时会切到对应合法配置，价格与预算始终按同一配置计算。当前分类无结果时可一键切换到有匹配项的分类。
- 年份 / 机龄和系列收进“更多筛选”，启用条件以可逐项移除的标签展示，并与配置复位保持独立。
- 默认先展示当前排序前 9 款，可一键展开其余结果，避免首次进入就浏览四十张卡片。
- CPU 单核、CPU 多核和 GPU 三项分开显示。
- 每一性能列独立归一化条形长度，当前结果中的该列第一名始终满格。
- 同一机型可切换多个官方芯片档，性能、价格、重量、续航、电源、接口、内存带宽、媒体引擎、外接显示器和 Apple 规格链接同步变化。iPad 的 WLAN / 蜂窝网络与适用机型的标准 / 纳米纹理玻璃也作为同一个目标配置的一部分联动。
- 屏幕、分辨率、刷新率、重量、电池 / 续航和接口在默认结果中直接可见，无需先进入对比或完整规格弹窗。
- 内存与存储采用单一“目标规格组合”选择器，避免生成不存在的配置。
- 支持 iPad Pro 容量—内存—CPU 绑定、M4/M5 iPad Pro 1TB/2TB 的纳米纹理选项，以及 MacBook Pro / Max 和 MacBook Air 低 GPU 档的专属容量 / 内存限制。
- 一键复位当前分类全部已调整配置，不改变筛选、排序和已保存的对比快照。
- 每次最多保存四个同品类的当前配置快照进行并排比较；按钮即时显示已加入状态，满四款后不会静默挤掉已有项目。不同品类使用不同性能基准，因此不会把百分比直接混在一张对比表里。
- 1450px 及以下优先使用价格前置的卡片，避免常见笔记本屏幕把价格藏到横向滚动区；大屏使用价格靠前的紧凑表格。
- 修改配置导致价格或性能排序变化时，会保持同一机型的滚动位置与控件焦点；若超预算被隐藏，会提供直接取消预算的入口。

## 性能评分

百分比是固定基准下的相对性能指数，不是发布会倍数，也不是主观打分。

- iPhone：A14 仿生 = 100%
- iPad：M1（iPad）= 100%
- MacBook：M1（8 核 CPU / 8 核 GPU）= 100%

Mac CPU 综合 Geekbench 6、Cinebench 2024 与 PassMark；GPU 综合 Geekbench Compute、同一子测试的 3DMark 和 FP32。各原始项先相对固定基准归一化，再使用加权几何平均。3DMark 还保存子测试 id，Wild Life Extreme 与 Steel Nomad Light 不会互相除算。

NanoReview 只作为公开跑分聚合入口之一，不使用其不透明的 Final Score。缺少某个降配芯片的独立聚合页时，优先查具体设备，再依据同架构相邻档实测和官方核心数推导缺失输入；最终三项性能分仍由统一公式计算。

完整权重、缺项处理和 M1 Pro 案例见[性能与二手价格技术报告](docs/technical-report.html)。

## 二手价格口径

价格是 2026-08 的静态选购估值，不是实时 API、成交保证或保值承诺。

- `闲鱼个人`：正常个人自用机的挂牌 / 近期成交模型估值。
- `转转验机`：带验机与售后服务的买家零售模型估值。
- 两个平台都用 `≈` 标明模型属性；都不是实时 API 或完整平台抓取。
- 平台回收价、故障机、监管机、扩容机和配件打包价不进入正常区间。

统一机况假设为：无激活锁或监管锁、无重大拆修和功能故障、屏幕完整，电池通常不低于约 85%。

旧版价格审计发现（当时尚未清除 Intel 非法组合，共枚举 1,273 组）：

- 转转数值几乎全部等于闲鱼乘约 85%，并非独立采样。
- 28 个高芯片档重复计算了绑定内存 / 存储差价。
- 当时枚举的 1,273 个配置中有 8 个出现 0 元端点。
- 老款 4TB / 8TB 配置可能错误保留近似新机选配差价。

当前模型包含 29 个显式绑定芯片、内存、存储和 `variantKey` 的配置锚点，占 1,552 个完整硬件 SKU 的 1.87%；自动检查会阻止默认策略或网络 / 玻璃选项变化后锚点静默换 SKU。技术报告只把有公开交易证据的部分称为样本，其余是结合相邻代际、公开促销上限与历史阶梯的模型输入。没有锚点的默认配置，按同类别、同系列和相近年份加权校准。芯片整包差价、组内内存 / 存储差价和网络 / 玻璃变体差价分别处理，避免 Max 或 iPad Pro 绑定配置重复计价。旧 Intel 高配不再使用会制造大量同价档的硬封顶，而是在允许上浮区间的 70% 处进入渐近式软饱和；自动检查要求同一合法升级路径的估值严格不倒挂且相邻档不完全相同。

当前所有转转区间都是基于闲鱼中点与类别服务溢价的模型值，尚未实现逐 SKU 转转实测覆盖分支，不会伪装成独立实测。购买当天可点击价格，用完整当前芯片 / GPU 档、内存、存储、网络版本与玻璃选项直接搜索平台复核；iPhone 搜索固定加入“国行”，避免把不同地区版本混进同一价格口径。iPad WLAN / 蜂窝的重量、续航、估值与搜索词都会随选择变化，M4/M5 iPad Pro 的纳米纹理选项也会同步联动。

iPad 蜂窝发布价差中，28 款来自 Apple 中国对应容量的精确价差，6 款较老机型使用多来源交叉先验；纳米纹理玻璃使用 `+800 元`发布价差先验。五款支持该选项的 M4/M5 MacBook Pro 使用 `+1,125 元`新机差价先验：当前 M5 配置器可直接核对，M4 则由同一 Apple 定价档和历史配置记录交叉确认。这些差价进入折旧模型，不代表二手市场会原额保留。

完整样本、折旧率、公式和修正前后案例见[技术报告的价格审计章节](docs/technical-report.html#market)。

## 验证

项目提供零依赖 Node.js 检查，要求 Node.js 18 或更高版本：

```bash
npm test
```

也可以直接运行 `node scripts/verify.js`；`npm run verify` 是等价入口。

当前检查覆盖：

- 产品数量与 2016–2026 年份边界。
- 所有芯片配置均存在必要性能输入。
- 官方合法 CPU / GPU / 显存 / 内存 / 存储组合、顺序和绑定关系。
- M1 Pro / Max、M2–M5 Pro / Max 的代表性配置约束，以及每档重量、续航、电源、接口、带宽、媒体引擎和外显字段。
- 2016–2019 Intel 独显 MacBook Pro 的 41 个官方 bundle，不再做 CPU × GPU 全排列；2019 16 英寸包含 5500M 4GB / 8GB 两档。
- 1,552 个价格结果均完成结构、数值与单调性验证：端点有限且为正、上下限有序，合法升级路径严格不倒挂且相邻档不完全相同；这不等于逐 SKU 实价已经得到市场确认。
- 不再存在“转转 = 闲鱼 × 0.85”的旧机械关系。
- iPhone 电池和未标注刷新率不会伪装成 Apple 官方数据。
- iPad 把 WLAN / 蜂窝和适用机型的标准 / 纳米纹理玻璃纳入可选 SKU，并联动重量、续航、价格、搜索词、Pencil 兼容性与 USB / 雷雳速率。
- Apple 未公布的 Mac 内屏刷新率不会写死 60Hz；ProMotion 固定刷新率完整保留。
- 3DMark 子测试不同或缺失时不会进入同一个相对比值。
- M1 Pro 8/14 不会高于 10/16，已确认的 Intel Cinebench 离群输入被隔离；Intel / Radeon GPU 分别使用 EU / CU。
- 29 个价格锚点显式绑定合法 SKU 与 `variantKey`，平台搜索词保留完整芯片、GPU 档、国行 / 网络和玻璃口径。
- MacBook Air M3/M4/M5 的低 GPU 档只保留 Apple 实际可搭配的内存 / 存储；MacBook Neo 的 256GB 档显示无 Touch ID，512GB 档显示 Touch ID。
- 2026 款 M5 Air 与 M5 Pro / Max 的 Apple N1 / Thread、iPad 的 Wi‑Fi 6E，以及旧 Mac 的精确蓝牙版本和外接显示器上限均有针对性回归检查；2025 基础 M5 MacBook Pro 仍按官网保留 Wi‑Fi 6E / 蓝牙 5.3，不混入 N1。

浏览器验收还覆盖配置切换、排序重排、一键复位、对比快照、响应式布局和控制台错误。

## 限制

- Apple 官方静态规格的验收目标是“当前快照逐页核对、零已知冲突”，不是无法证明的永久 100%。
- 跑分会受到系统版本、功耗、散热和样本结构影响。
- 性能指数适合比较硬件层级，不代表每个 App 都会按相同比例加速。
- 闲鱼和转转完整搜索结果依赖登录和动态加载，本站没有声称全站实时抓取。
- 稀有 CTO、AC+、地区版本、成色和电池状态可能使实际价格明显偏离估值；iPhone 的页面搜索与价格解释固定为国行口径。
- iPad 蜂窝与纳米纹理、MacBook Pro 纳米纹理已经建模，但发布价差先验不等于二手成交差价；保障与配件仍不建模。
- 老 Intel 稀有高配在 70% 上浮拐点后使用渐近式软饱和，以保留档位顺序和差异；它仍是样本不足场景下的模型约束，不代表逐档市场实价。
- 颜色、单独购买的电源适配器、保障和其他配件不属于本站定义的机器核心硬件 SKU，也不计入 1,552 组。
- 历史精确日期混合发布、预订和首售口径，只作为同年排序键；产品页只承诺并展示推出年份。
- 亮度、摄像头或无线连接等尚未逐页录入的扩展字段会明确显示“见 Apple 官方规格”，不纳入“零已知冲突”声明，也不会用推测值补空。
- 数据更新时应保留样本日期、具体配置与来源，不能只修改一个没有证据的百分比或价格。
